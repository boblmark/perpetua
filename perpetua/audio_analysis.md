## 一、外部研究结论

### 1.1 定量结论（有数字的）

| 结论 | 数字 | 来源 |
|---|---|---|
| 中等情绪唤醒的音频最有效：基频 340–360 Hz、响度约 50–60 dB、语速 4–5 词/秒 | 340–360Hz / 50–60dB / 4–5词/s | MDPI 短视频营销研究（influencer 短视频，N 未公开） |
| 视听强度必须匹配：高视觉变化配高唤醒音频，低配低；错配导致认知失调、参与度下降 | 定性方向 + 上述参数 | 同上 https://Www.Mdpi.com/0718-1876/20/2/69 |
| teaser 型钩子（前 2 秒揭示 payoff 味道但不给全）首 3 秒首播通过率提升 | 1.7x lift | Nielsen 2026（经 linkupsocialmedia 转述，原始报告未公开） |
| 前 1.7–3 秒流失 | 50–60% 观众划走 | 多源共识（deepak-skill 引 OpusClip/housesparrowfilms 2026；方向性数字，非 primary study） |
| 60–80% 的 Shorts 静音观看 | 60–80% | 同上；多源共识 |
| 动态/逐词字幕提升留存 | +15–25% | 同上 |

### 1.2 定性结论（找不到量化数字，诚实标注）

1. **"第一秒是结构，不是音乐"**（Medium, Sound Controls Attention）：
   - 慢淡入的 pad 再美也无效；percussive hit、sharp transient、突然转静音才是"进入感知的入口"
   - "没有静音就没有冲击力"（If there is no silence, there is no impact）
   - 来源：https://medium.com/@universocandura/sound-controls-attention-ada0ca5cce90

2. **音频打断技术清单**（GitHub gaspol-video， practitioner 共识非学术）：
   - Strategic Silence：VO 开始前 0.5–1s 死寂
   - Single Percussive Hit：一次 bass drop/drum hit 然后静音
   - Music Genre Shift：第一秒内突然换曲风
   - 组合技 "The Ambush"：Music drop → silence（TikTok teaser 推荐栈）
   - 来源：https://github.com/alisadikinma/gaspol-video/blob/HEAD/reference/storytelling_script_gen/F11_Pattern_Interrupt_and_Retention.md

3. **开头音效类型对比**：未找到"静音突响 vs 持续 BGM vs 自然声"三者对 3 秒留存的**对照实验数据**。这是公开研究的一个空白。

4. **音频动态范围 vs 完播率**：未找到直接的量化对照研究。最接近的是上面 MDPI 的"中等唤醒最优"（两端都不好：太平淡无聊、太激烈过载）。

### 1.3 对我们的直接启示

- 60–80% 静音观看 → 音频是"加分项"不是"生死项"，但对开声音的 20–40% 观众，第一秒的 transient 决定去留
- "突然静音后接清脆 Foley"（第一轮研究结论）与本轮 "silence = preparation" 互相印证
- 没有证据支持"全程高亢 BGM"；证据指向"有对比、有呼吸"的动态设计

## 二、我们自己视频的音频分析

### 2.1 方法

`ffmpeg astats` 每 0.5s 窗口取 RMS_level，画 10s 包络；`volumedetect` 取整体 mean/max。

### 2.2 结果（8 个文件）

| 文件（简称） | 首0.5s (dB) | 整体动态范围 (dB) | 包络形状（每0.5s） |
|---|---|---|---|
| 3756cd | -57 | 38.6 | -57 -52 -40 -22 -18 -19…（静音渐强，2s 到顶） |
| 6ab5ab | -48 | 35.0 | -48 -19 -14 -13…（1s 内跳起） |
| db8b13 | -55 | 40.2 | -55 -50 -49 -26 -21 -22…（慢渐强） |
| 986fd8-hall | -31 | 21.5 | -31 -22 -15 -11 -10 -9…（较快起音） |
| b188c3 | -30 | 17.5 | -30 -31 -18 -14 -13…（先抑后扬） |
| karenvsai-pilot-01 | -40 | 16.1 | -40 -39 -38…-28（全程缓慢爬升，无峰） |
| 20261005102217 | -23 | **3.0** | -23 -23 -23…（全程一条直线，恒定底噪） |
| youtube-viral-short | -27 | 11.2 | -27 -28 -29 -29 -21 -19…（2.5s 处突然跳起） |

整体 mean_volume：-16.8 ~ -23.2 dB；max_volume：基本 -0.1 ~ -0.8 dB（无削波）。

### 2.3 三个肉眼可见的发现

1. **首 0.5s 能量跨度 34dB**（-57 ~ -23）：模型对"开头怎么响"完全没有一致性。有的近乎静音开场（3756cd，暗合"strategic silence"），有的一上来就是 -23dB 的恒定噪音（20261005102217）。
2. **动态范围两极分化**：3 个文件 >35dB（大起大落），2 个 <17dB（平淡），1 个只有 3.0dB（一条直线——基本可以判定为无意义的底噪/电流声，不是设计过的声音）。
3. **没有一个文件在 0–0.5s 有明确的瞬态峰**（percussive hit）：所有"跳起"都发生在 1–2.5s，是渐强不是"砸"。按 1.2 节的理论，第一秒缺少"进入感知的入口"。

### 2.4 样本局限（诚实说明）

- **无法做"爆款 vs 哑火"对照**：这 8 个是本地生成候选文件，Marvis 在腾讯侧上传，本地没有"哪个文件对应哪个 YouTube video_id → 播放量"的映射表。`mcp_jobs/done/*.result.json` 只有文件名和标题，没有 video_id。
- 8 个样本全部来自 AI 生成，没有真人实拍对照组。
- 因此本节是**描述性统计**，不是因果结论。

## 三、可落地的音频门禁升级建议

### P0（可直接写进 pre_upload_qc.py，0.5 天）

| # | 门禁 | 具体指标 | 依据 |
|---|---|---|---|
| A1 | 开头瞬态检查 | 0–1s 窗口内 max RMS − min RMS ≥ 10dB（必须有"起来"的动作）；或首 0.5s < -45dB 且 1–2s 内上升 >15dB（strategic silence 模式也算过） | 本轮 2.3：现在有的文件是"渐强"有的是一条直线，需要一条线把"死音频"拦下来 |
| A2 | 死音频拦截 | 全片动态范围 < 6dB → reject（`20261005102217` 的 3.0dB 就是反例：恒定底噪不是声音设计） | 本轮实测反例 |
| A3 | 结尾拖尾（已有 tailcut，再加一条） | 最后 1s 能量 > 前 2s 均值的 70% → warn（已在 pre_upload_qc 有雏形，确认阈值） | 第一轮"abrupt end"共识 |

### P1（需要后处理管线支持，2–3 天）

| # | 动作 | 说明 |
|---|---|---|
| A4 | 生成后统一响度 | 全片 normalize 到 -16 LUFS（Shorts/移动端标准），解决 mean_volume -16.8 ~ -23.2 的 6dB 散布 |
| A5 | 0 秒 Foley 强制注入 | 模型给不出瞬态（2.3 发现 #3），就别指望模型：后处理在 0–0.3s 叠一层清脆 Foley（门铃/快门/拍手，按场景选），这是"让失败无法表达"的结构约束 |
| A6 | 音频指纹入库 | 每个生成文件存一份包络指纹（10 个 1s 窗口 RMS），发布后 48h 回流播放量时做关联分析——这是补上 2.4 缺口的唯一方法 |

### P2（等数据回流，持续）

- A7：积累 50+ 条"音频指纹 → 完播率"配对后，跑相关性，回答"首秒瞬态强度是否预测 3 秒留存"
- A8：如果 A7 证实，升级为 jev/virality 模型的音频特征维度

## 四、一句话总结

模型生成的音频**方差极大且无设计意图**（首秒 -57 ~ -23dB，动态 3 ~ 40dB），指望 prompt 修好是不现实的——按"结构约束胜过 prompt 措辞"的原则，正确做法是：**门禁用 A1/A2 拦死音频，A5 用后处理强制注入 0 秒 Foley**，A6 把指纹存下来等数据回流验证。
