## 六大舱壁（v3.1 更新）

1. **降级自治模式**：大脑失联时手侧按最后已知策略继续
2. **脑外独立看门狗**：不依赖大脑的存活监控
3. **QC 熔断器**：60s fail-closed
4. **状态存储解耦**：WAL 独立存储
5. **人工终极开关**：L1/L2/L3 三档 Kill Switch
6. **🆕 意图防火墙**（Kimi 补丁）：代理指标 vs 人工抽审质量偏离时冻结进化

## MVP 实施顺序（v3.1 锁定）

```
Week 1:
  Day 1: 质量地板门禁（三模型原始样本人类评分）
  Day 1-2: 安全 Phase -1 + 6 防火墙 + 进化冻结开关
  Day 3: 目标函数锁定 + 因果库建表 + 脑机契约接口冻结
  Day 4-5: 每日 SOP 骨架 + 人工创意入口 + 单层信号仪表盘
  
Week 2:
  人类创意入口护栏 + 手动面板（含 RBAC）
  L1 进化引擎（默认冻结，需手动解冻）
  
验证门:
  目标函数有预测力？→ 是则开放 L1/L2 → L4 永远最后
```

## 关键设计决策（v3.1 新增）

1. **"人就是系统的ε"**：人工创意 = Bandit 探索位的人类来源，打标签进因果库
2. **"不产生数据的生产系统是沉没成本"**：目标函数+因果库第一天就绪，否则不准生产
3. **"保护意图"与"保护生存"分离**：6 大舱壁中 5 个保生存，1 个保意图
4. **进化默认冻结**：任何自动突变都是 opt-in，不是 opt-out
