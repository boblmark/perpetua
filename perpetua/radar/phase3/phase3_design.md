# Phase 3 设计：抖音 / 视频号 / 快手 / 小红书 自有账号数据接入

决策 [D20261017-002] 三档：这四个平台**只接自己账号的官方数据**（OAuth 授权后读自己视频的播放/点赞/评论）。
国内竞品爬虫、TikTok/FB/X 竞品监测——**明确暂缓**，原因见文末。

> 统一红线：雷达只读（D20261016-007 冻结期至 2026-12-10，禁自动快车道）。
> 本阶段四个脚本均为 stub：打印接入步骤后退出，不采集任何数据。
> 精确的接口路径以各平台开放平台控制台最新文档为准（文档常变，stub 里不写死）。

## 一、抖音（账号：抖音号 43833679345）

- 开放平台：open.douyin.com（抖音开放平台）
- 用户需完成：
  1. 用手机号/营业执照注册开发者账号（个人可注册，企业号能拿到更多 scope）。
  2. 控制台创建应用 → 选择「移动应用/网站应用」按实际形态选。
  3. 在「能力」页申请视频相关 scope：`video.list`（自己的视频列表）、`video.data`（自己视频的数据：播放/点赞/评论）。
     这两个 scope 需要用户（即账号本人）在授权页扫码同意。
  4. 把应用的 `client_key` / `client_secret` 经保险库（Secure Vault）交给 Dash，
     绝不在聊天/文件里贴。
  5. 授权回调地址填 Dash 指定的公网地址（走 viralloopapp.com 反代隧道）。
- 接入后能拿：自己每个视频的累计播放/点赞/评论 → 直接进 radar.db（platform='douyin'），
  走同一套快照差分 + outlier。
- 拿不到：任何别人的视频数据（官方不提供竞品接口）。

## 二、视频号

- 入口：微信公众平台 → 视频号助手（channels.weixin.qq.com）。
- 用户需完成：
  1. 视频号完成实名/企业认证。
  2. 在「设置 → 授权管理」把 Dash 的数据应用加入第三方授权（或用官方「视频号数据」
     导出能力定期同步）。
  3. 如走开放平台 API：mp.weixin.qq.com 注册，在视频号相关接口权限里申请
     「获取视频号动态/数据」类接口，拿到 appid/secret 经保险库交付。
- 接入后能拿：自己视频的播放/点赞/评论/转发 → platform='weixin_channels'。
- 拿不到：竞品视频号数据（无公开接口）。

## 三、快手（账号：CGB2024）

- 开放平台：open.kuaishou.com（快手开放平台）。
- 用户需完成：
  1. 注册开发者账号并完成实名认证。
  2. 创建应用 → 申请「内容开放」类目下的视频数据权限（用户视频列表、视频详情/统计）。
  3. 用快手 App 扫码完成账号 OAuth 授权（授权自己账号的数据权限）。
  4. `app_id` / `app_secret` 经保险库交付。
- 接入后能拿：自己作品的播放/点赞/评论 → platform='kuaishou'。
- 拿不到：竞品数据。

## 四、小红书（账号：档案管理员 / 267112808）

- 开放平台：open.xiaohongshu.com。小红书创作者数据主要走「蒲公英」「千帆」商业后台，
  纯内容创作者的数据接口最弱。
- 用户需完成：
  1. 小红书专业号/企业号认证（个人号数据接口几乎没有）。
  2. 在开放平台创建应用，申请笔记数据相关权限；如只有蒲公英后台权限，
     改用「蒲公英后台 → 数据导出」半自动同步（CSV 导入 radar）。
  3. 凭据经保险库交付。
- 接入后能拿：自己笔记的阅读/点赞/收藏/评论 → platform='xiaohongshu'。
- 拿不到：竞品数据。市面上的「小红书代采 API」全是 APP 逆向（xsec_token/签名），
  按决策不采用。

## 五、明确暂缓（不做）

1. **国内竞品爬虫**（抖音/快手/小红书/视频号的别人数据）：官方无接口，
   只能逆向（设备指纹、签名算法、账号池），违反平台 ToS 且维护成本极高
   （一个签名升级就全断）。投入产出比不成立，暂缓。
2. **TikTok 竞品监测**：Research API 只批学术/非营利机构，商业用途基本被拒；
   Display API 只能拿用户自己授权的数据；Business API 只管自己的企业号。
   官方路走不通，暂缓。
3. **Facebook 竞品监测**：Graph API 主要是自己的 Page/公共主页受限读取，
   Content Library 有粉丝量门槛且面向研究场景。暂缓。
4. **X 竞品监测**：公开帖子指标要走付费 API（Basic $100/月起），
   按当前需求不值得，暂缓。
