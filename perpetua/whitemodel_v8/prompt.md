## 三、参考图提示词（产线 C）

这张图的职责是**锁材质与光线，不锁构图**——构图和机位归白模管。所以下面这段刻意不写机位、景别和任何物件的画面位置；十几张参考图如果各自都带构图倾向，会把镜头拽向十几个方向。

尺寸出 **1440×2560**。长边别低于这个档位——参考图分辨率不够会把成片质感一起拉下来。

```
实拍质感，ARRI Alexa，竞技场现场灯光，轻微手持抖动。
拳击擂台，CCTV 风格固定机位 CAM 03，现场观众围满四周，擂台蓝 canvas，红蓝围绳。
画面里穿粉色运动服的金发女人 Karen，[尺度参照物——让观众读出这东西有多大的那个东西]。
[大气介质：体积光柱／丁达尔光锥／悬浮尘埃／雨雾／热浪扰动。空气必须是可见的，这是大片感的核心]。
[戏剧性布光：低角度侧逆光／大光比／轮廓光，主光从哪个方向来，暖冷对比。图库照片才是均匀曝光]。
[实拍瑕疵：划痕／油渍／锈迹／镜头眩光]。
实拍照片质感不是CG渲染不是概念插画，Kodak Vision3 胶片颗粒，高动态范围，暗部深沉保留细节，高光柔和滚降不过曝，轻微暗角。
画面内容完整填满整个9:16画幅，不要黑边，不要信箱式黑框，不要边框装饰
```

出图后统一裁边（即便写了「不要边框」仍可能残留一圈细描边）：

```bash
ffmpeg -y -i 参考图.png -vf "crop=iw-72:ih-72:36:36,scale=1440:2560" 参考图-已裁边.png
```

六要素自检（缺一件就掉档）：真实片名锚点 · 器材规格 · 大气介质 · 尺度参照物 · 戏剧性布光 · 实拍瑕疵。

两条硬避坑：**不要写「变形宽银幕」/「anamorphic」**（模型会把信箱式黑边一起画进画面，Seedance 会连边框一起继承）；**必须明写「实拍照片质感不是CG渲染不是概念插画」**（否则出来的是概念艺术图，漂亮但假，色调容易塌成单一冷蓝）。

## 四、发出去之前逐条过一遍

- [ ] 方括号占位全部填掉了（一个都不能留）
- [ ] 每个参考素材都写了「继承什么」和「不继承什么」——漏掉「不继承」，模型会把参考里的一切都端过来
- [ ] prompt 里的朝向描述和白模一致（抽帧看主体的鼻子和胸标朝哪，别靠记忆）
- [ ] 每一段都同时交代了「镜头怎么动」和「主体做什么」，缺一样模型就自由发挥另一样
- [ ] 负面约束具体到「排除哪个错误品类」，没写「不要低质量」这种废话
- [ ] 风格锚点用的是真实片名和器材型号，不是「电影感」「高级」
- [ ] 切点时间与事实表一致（成片帧率可能与白模不同，切点仍然会对齐，实测误差 < 1 帧）
