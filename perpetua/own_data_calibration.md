## 二、三个颠覆性发现

### 2.1 "AI" 在标题里是负变量（但有重要例外）

- 含 AI 标题（n=76）：几何均值 156 vs 不含 AI（n=420）：703 → **0.22x**
- Pearson -0.287，是除时长外最强的负变量
- **但**：品牌前缀的 9 条（2025-10）：几何均值 **2205**，包含全频道最高 30,676 播放
- 普通 AI 提及（n=67）：几何均值仅 109

**解读**："AI Satire" 是一个成功的**品牌系列格式**，不是关键词 "AI" 本身有效。随手在标题里加 "AI" 不但没用，反而可能稀释。当前门禁要求"含 Karen/AI"（二选一）——数据说应该改成**"含 Karen 优先，AI 仅在品牌系列语境下有效"**。

### 2.2 数字标题有害

- 含数字（n=104）：几何均值 236 vs 不含：701 → **0.34x**，Pearson -0.235
- 可能原因：数字让标题像剧集编号（"Complaint #4"）或营销号，降低点击欲
- **建议**：门禁加一条——标题避免纯数字编号

### 2.3 Karen 被低估了（近期批次稀释了它）

- 全量：1.35x；但只看 2026-10 之前的老视频：**1.78x**（958 vs 537）
- 近期哑火批次大量非 Karen 标题拉低了整体
- Top10 中 4/10 含 Karen——考虑到全频道只有 29% 含 Karen，Top10 中 40% 已是富集

## 四、给 v3 模型的权重调整建议

基于本频道数据（Pearson 绝对值归一化，符号保留）：

```
# 建议 v3 权重（总和 100）
emoji_present: +18 # 最强正变量
is_shorts: +16 # 35x 差异，但接近常量（95% 已是 Shorts）
emoji_first: +12 # 3.43x
verb_tier_S: +10 # S级 3.59x
verb_tier_B: +5 # B级 1.46x
has_karen: +8 # 老视频 1.78x，用 8 不用 3（近期稀释是噪音）
fk_grade_low: +6 # FK≤5 加分
friday_bonus: +4 # 周五发布
has_tags_3plus: +3 # 1.51x
---
duration_long: -10 # 时长是最强负变量
has_ai_generic: -8 # 普通AI提及（非品牌系列）
has_number: -7 # 数字标题
has_cjk: -15 # 中文标题（硬拒绝，不只是扣分）
verb_banned: -20 # 禁用动词（硬拒绝）
```

**关键调整**（相对 v2）：
1. `has_ai` 从正权重改为**负权重**（-8），但品牌系列豁免
2. 新增 `has_number` 负权重（-7）
3. `has_karen` 权重上调（老视频 1.78x 比全量 1.35x 更可信）
4. `duration` 首次进入模型——>30s 直接重罚
5. `emoji` 拆成两个变量：存在（+18）+ 开头（+12），可叠加

## 五、数据缺口（下次补）

1. **发布时间小时级**：API 的 published 字段只有日期。需要改 fetch_all.py 拉 `snippet.publishedAt` 完整时间戳。
2. **播放中行为数据**：完播率、循环率、平均观看时长——需要 YouTube Analytics API（已有 youtube_analytics 工具，下次拉 90 天数据做关联）。
3. **CJK 样本太少**（n=1）：等 bypass_audit 拦截更多案例后重新评估。
4. **Top10 视频的播放中变量**：循环率、首帧特征等需要下载视频文件分析（pre_upload_qc 的逆向工程）。
