# Phase 1: 万网下单流程（browser 任务）

## 1. 登录
- 打开 `https://wanwang.aliyun.com/`，走扫码登录（用户用阿里云 App / 支付宝 / 钉钉扫）。
- 登录二维码截图发给用户，等用户说"登录好了"再继续。

## 2. 查域名、加入清单
- 在万网搜索框输入目标域名，确认可注册、记下首年价和续费价，报给用户确认。
- 点"立即注册"，进入订单确认页（`wanwang.aliyun.com/buy/commonbuy`）。
- 不要勾选 AI 建站等附加项。

## 3. 实名信息模板（dc.console.aliyun.com）
下单要求选择一个实名认证过的信息模板；没有模板就点"创建信息模板"。
必填项（全部用用户提供的值）：
- 证件类型：居民身份证
- 域名持有者姓名 / 证件号码
- 手机号码
- 电子邮箱（需完成邮箱验证；QQ 邮箱可能收不到验证码，提醒用户备选）
- 所属区域（省/市）/ 通讯地址 / 邮编
- 持有者证件上传：身份证正面彩色照片，JPG/PNG，55KB–5MB，边框完整

坑：
- 阿里云控制台的"产品面板"悬浮窗可能盖住提交按钮且程序关不掉 → 让用户接管浏览器手动关掉面板（或直接点提交），再继续。
- 刷新页面会清空未提交的表单；提交前确保照片已重新上传。

## 4. 提交订单、停在付款页
- 回到订单页 → 选中模板 → 勾选《域名服务条款》→ 点"立即购买"。
- 到付款页**停下，不付款**（见 SKILL.md Operating Rules 第 4 条）。
- 把订单号、金额、付款方式（阿里云 App → 费用 → 待支付订单）告诉用户，等用户付款。
