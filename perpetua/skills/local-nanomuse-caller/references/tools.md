# nanoMuse 工具列表 (29 个)

## 媒体生成
- `tts`: 文字转语音 (MP3)
- `generate_image`: AI 图片生成 (agnes-image)
- `generate_video`: AI 视频生成 (geminigen/vids/agnes-video 多后端)

## 搜索
- `web_search`: 网页搜索
- `web_fetch`: 抓取网页内容
- `social_search`: 社交媒体搜索
- `shopping_search`: 商品搜索比价
- `maps_search`: 地点搜索
- `image_search`: 图片搜索

## 浏览器
- `browser`: Playwright 浏览器自动化

## 通信
- `read_emails`: 读 Gmail
- `send_email`: 发邮件
- `calendar`: 日历 (ICS)

## 系统
- `shell`: 执行 shell 命令
- `python_execute`: 执行 Python
- `files`: 文件操作

## 智能体
- `subagents`: 子代理
- `coding_agents`: 编程代理
- `skills`: 技能管理

## 记忆与目标
- `remember` / `recall` / `forget`: 记忆
- `goals`: 目标管理
- `reminders`: 提醒
- `cron`: 定时任务
- `triggers`: 触发器
- `contacts`: 联系人

## 交互
- `ask_user`: 询问用户
- `terminate`: 结束
