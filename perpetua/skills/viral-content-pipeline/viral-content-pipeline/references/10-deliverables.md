## 主交付：`competitor_viral_<日期>.xlsx`

### Sheet 结构（顺序即交付顺序）

| # | Sheet | 内容 |
|---|---|---|
| 1 | `summary` | **必须放第一位**：可行性总览、如何使用本表、各平台账号清单、抽样口径与已知偏差、真实性核验记录、补齐路径 |
| 2–N | `<platform>` | 每平台一个 sheet，首行字段名 |
| N+1 | `analysis_benchmark` | 互动率基准 |
| N+2 | `analysis_content` | 内容规律统计 |
| 末 | 不可得平台 | 空表 + 缺口说明（不要省略！） |

**不可得平台也要建表**，在表内写明原因。直接不建表会让人以为漏了。

### 硬性要求

- **零空单元格**：所有 `None` / `""` 统一转 `"N/A"`
- 表内数字与 `analysis.json` 一致（分析 sheet 从 JSON 生成，禁止手写）
- 首行字段名固定，便于下游程序消费

## 结论层：`爆款方法论_<日期>`

### 双输出策略（Word + PDF 同源）

用**同一个内容模型**渲染两种格式，避免两版不一致：

```
build_content() → [{type:h1/h2/p/ul/table/callout}, ...]
                    ├── render_docx()  →  .docx（≤10 页）
                    └── render_html()+chromium → .pdf（≤30 页）
```

**实现要点**：
- 中文字体：`Noto Sans CJK SC` / 微软雅黑，`python-docx` 需同时设 `rFonts` 的 `w:eastAsia`
- PDF 用 Playwright 的 `page.pdf(format="A4", print_background=True)`
- 页数校验：`len(PyMuPDF.open(pdf))`

### 内容结构（9 章 + 附录，本次实践验证有效）

```
零、先读这三句        ← 铁律与样本量声明
一、互动率基准        ← 各平台对表 + 反直觉发现（callout 高亮）
二、选题方向          ← 分布 + 可直接抄的选题母题
三、开场钩子          ← 与基线对比
四、时长策略          ← 最有信息量的一节
五、标题与标签        ← 长度 + 结构 + 找反例
六、封面风格          ← OCR + 像素级实测
七、系列化与形态
八、平台速查表        ← 一表总结各平台策略
九、边界与限制（必读）
附录 A/B/C            ← 账号清单 / 样片索引 / 口径与复核方式
```

### 用 `callout` 高亮三类内容
1. **反直觉发现**（如"爆款赢在绝对触达"）
2. **行动清单**（可执行建议）
3. **警告**（如"该项无规律，别花时间"）

## 单页版：`爆款方法论_一页纸.pdf / .png`

A4 单页，6 个模块 + 行动清单（**✓ 照做 / ✕ 别做** 两栏）。投屏/贴工位用。

**CSS 陷阱**：模板里用 `{ACCENT}` 这类占位符时，**必须写 `#{ACCENT}`** —— 漏掉 `#` 会让
`background: 2F5597` 成为无效值，表头文字直接不可见（且白色文字会隐形，非常隐蔽）。

## 样片库：`样片库_<日期>.xlsx`

从全量数据中**精选**（30–40 条），覆盖：
- 每平台头部爆款
- 对照组中位样本（体现"同账号的常规落差"）
- 结构特殊样本（超长/超短/高收藏/高转发）

每行附**量化特征**（由该行真实数字直接计算）+ **入选理由**。
链接做成超链接，供直接拉片。

**去重**：同一视频可能被多条规则选中（如"账号头名"和"最高收藏"），必须按 `video_url` 去重。

| 四、字段说明与边界 | |
| 五、未拿下 + 补齐路径 | 诚实列出 |
| 六、目录结构 | |
| 后续章节 | 按需追加（如新增平台突破、第三方工具实测） |

### 核验记录的写法

每条都要有**具体数字**，不能只写"已复核"：

```
B站：独立复采 4 条 → 自然增长（8,327,176 → 8,327,220，+44）✅
TikTok：池内 15,100,000 vs 实时 playCount:15100000 完全一致 ✅
快手：定向复验 3 条 → 2 条成功（8,416,123 → 841.6万、likes 357,668 → 357,670）✅
抖音：**未能独立复核**（详情与列表接口登出态不可用）—— 此限制如实记录
```

```python
# 1. 行数
sum(wb[s].max_row-1 for s in platforms) == 预期总行数
# 2. 空单元格
blank = 0  # 必须为 0
# 3. 页数
len(PyMuPDF.open(pdf)) <= 上限
# 4. 文档数字与 analysis.json 一致（抽查关键数字）
# 5. 样片库去重
len(urls) == len(set(urls))
```
