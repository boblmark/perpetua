把 `*_rows.json` 变成 `analysis.json`，再变成可信的结论。
参考实现：`scripts/analyze/step8_analysis.py`、`scripts/analyze/step9d_cover_visual.py`

## 一、互动率基准

### 口径

**互动率 = 互动数 ÷ 播放量，取组内中位数**（不是平均值 —— 避免被极端值带偏）。

分别对爆款组、对照组计算：`点赞/播放`、`评论/播放`、`转发/播放`、`收藏/播放`。
缺失值不参与统计，**每个单元格标注实际样本数**。

### ⚠️ 最重要的发现：不要假设"爆款互动率更高"

本次 288 行实测（中位数）：

| 平台 | 爆款组点赞/播放 | 对照组点赞/播放 | 差异 |
|---|---|---|---|
| B站 | 3.40% | 3.40% | **几乎完全相同** |
| TikTok | 4.99% | 4.24% | 爆款略高 |
| 快手 | 4.40% | **5.68%** | **对照反而更高** |
| X | 0.435% | 0.39% | 接近 |

> **结论：爆款赢在绝对触达，不在单位互动效率。**
> 实操含义：判断内容能不能爆，看的是绝对播放量级；**不要把互动率当爆款预测器**。
> 预算与选题会的时间应花在复制选题、时长与形态上。

这条反直觉结论是本流水线最有价值的输出之一 —— 如果只报告"爆款互动率更高"，
就等于输出了错误结论。

### 平台不公开播放量时的替代口径

抖音播放量不公开 → 改用 **`收藏/点赞`** 表示，并在表内标注口径：

```
抖音：播放量不公开 → 互动率改以「收藏/点赞」表示
爆款组 12.67%  vs  对照组 22.96%
```

**注意**：该口径下对照组反而更高，说明它**不等于爆款信号**，只能作参考，不能当基准用。
这一点必须写清楚，否则读者会误用。

## 二、内容维度统计（`analysis_content`）

| 维度 | 做法 | 输出 |
|---|---|---|
| **选题分布** | 按 `topic_category` 分组计数 | 平台 × 分类 × 条数 × 占比 |
| **开场钩子 × 爆款占比** | 按 `hook_type` 分组，算组内进爆款组的比例 | 与**该平台基线**对比 |
| **时长 × 表现** | 分档（＜30秒 / 30-60秒 / 1-3分钟 / 3-10分钟 / ≥10分钟），算组内播放中位、点赞中位 | 每平台找出最优档 |
| **标题长度 × 表现** | 分档（≤15字 / 16-30字 / 31-50字 / ＞50字） | 中位播放对比 |
| **标题结构 × 爆款占比** | 用正则检测特征（含数字/疑问句/剧集编号/emoji/标签） | 与基线对比，**找反例** |
| **封面文字（OCR）** | 有文字 vs 无文字两组的爆款率 | 见下 |
| **系列化** | 正则匹配「第N集/第N话/EP\d」 | 占比 + 爆款率 |
| **高频标签** | 标签词频 Top N | 平台标签习惯 |

### 时长结论示例（本次实测真实结论）

- **TikTok**：1-3 分钟中位播放 **930 万**，是 ＜30 秒档（77.3 万）的 **12 倍** —— 长一点反而更能跑量
- **抖音**：≥10 分钟 **4/4 全进爆款组**，点赞中位 9.07 万，是 1-3 分钟档（9,197）的约 **10 倍**
- **快手**：1-3 分钟最高（98.8 万），3-10 分钟最低（31.3 万）
- **B站**：1-3 分钟中位播放最高（54.0 万）

→ **快手与抖音的时长规律相反** —— 说明必须**分平台**给结论，不能给全局建议。

## 三、封面分析（两层）

### 第一层：OCR 文字

下载封面图 → OCR 提取 → 分"有可识别文字" vs "无可识别文字"两组，比爆款率。

**必读提醒**：**「未识别」≠「封面无文字」**，须声明需人工复核。

本次实测（反直觉）：
- B站：带字 48% vs 无字 54%
- TikTok：带字 47% vs 无字 57%
- → **无文字组反而略高。推翻"封面必须写大字"的常见假设。**

### 第二层：像素级视觉指标

对封面原图做客观测量（**这些是测量，不是推断**）：

| 指标 | 计算方式 |
|---|---|
| 亮度 | 相对亮度均值（`0.2126R + 0.7152G + 0.0722B`） |
| 饱和度 | HSV 的 S 均值 |
| 对比度 | 亮度标准差 |
| 暖色倾向 | 平均 `R − B`（>0 偏暖） |
| 视觉复杂度 | Sobel 梯度均值 |
| 高饱和占比 | `S > 0.5` 的像素比例 |
| 暗部占比 | 亮度 `< 0.25` 的像素比例 |
| 画幅比 | 宽 / 高 |

### ⚠️ 必须做显著性检验（否则会把噪声当规律）

**置换检验（permutation test）**：把两组标签打乱重排 N 次（建议 20000），
看观测到的中位数差在随机分布中的分位。

**本次实测结果 —— 这是一节"无规律"的价值示范：**

> 28 项组间检验中，**仅 1 项达 p<0.05**（快手高饱和占比 0.320 vs 0.124）
> —— 而 28 项检验在 p<0.05 下本就约会出现 **1.4 项假阳性**，不足以支撑结论。
>
> 且 **B站方向相反**（爆款饱和度 0.240 < 对照 0.373，p=0.074 边际）——
> 说明封面规律是**平台相关**的，不存在全网通用配色公式。
>
> 唯一稳定差异是**画幅比**：TikTok 139/140 竖屏、B站 68/80 横屏
> —— 由平台产品形态决定，不是创意选择。

**结论：不要在"爆款配色/爆款构图"上花时间。**
封面差异更可能由**账号自身风格**驱动，而非爆款属性。

> 敢写"这项没规律"比编一条"爆款配色"更有价值 —— 它直接帮客户省下了无效工作量。

## 五、写作纪律

1. **每个数字都必须来自 `analysis.json`** —— 禁止在文档里手写数值（会导致文档与数据不一致）。
2. **小样本必须标注**。写"仅作方向参考，不作阈值承诺"。
3. **报告反例**。若某特征方向不一致或低于基线，要写进正文（如"疑问句标题在 TikTok/抖音低于基线"）。
4. **口径变化必须显式声明**。换了统计口径（如抖音改用收藏/点赞），要在表内和正文都标注。
5. **区分"描述性统计"与"阈值结论"**。288 行是抽样不是普查，不做精确阈值推断
   （完播率/留存等后台指标本就不在范围内）。
