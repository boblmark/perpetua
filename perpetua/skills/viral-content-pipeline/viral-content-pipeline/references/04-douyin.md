# 04 · 抖音 — 播放量永远拿不到

**可行性**：⚠️ 部分可得。点赞/评论/转发/收藏 + 粉丝数可采；**播放量平台不公开**。

---

## 最重要的一条：播放量必为 N/A

抖音网页端接口返回的 `statistics.play_count` **恒为 0**。这不是 bug、不是被拦、不是缺参数 ——
**是平台不公开该字段**。

→ 处理方式：`views` 一律写 `N/A`，抽样改用**点赞量**排序，并在 `sampling_frame` 标注：

```
"按点赞排序分高/中位两组（平台不公开播放量）"
```

**绝对不要**用「点赞数 ÷ 经验系数」反推播放量 —— 那是编造。

---

## 可用接口

| 用途 | 接口 | 说明 |
|---|---|---|
| 内容池 | `module/feed`、`channel/hotspot` | 返回真实 `digg_count` / `comment_count` / `share_count` / `collect_count` |
| 账号粉丝 | `aweme/v1/web/user/profile/other/` | 返回账号统计（粉丝数） |

- 数据取自平台自身 feed 接口的实时返回，字段内部自洽（可交叉验证）
- 账号粉丝补全：用 Playwright 打开 `https://www.douyin.com/user/<sec_uid>` 提取

## 已知边界

| 能力 | 状态 | 说明 |
|---|---|---|
| 播放量 | ❌ | 平台不公开（恒为 0） |
| 作品详情页 | ❌ 登出态 | 视频详情接口登出态不可用 |
| 账号作品列表 | ❌ 登出态 | 主页返回 0 条作品 |
| **独立复核** | ❌ | **见下方重要说明** |
| 手工构造 `module/feed` | ❌ | 返回 `Unsupported path(Janus)` |

### ⚠️ 抖音数据无法独立复核 —— 必须在交付中如实声明

因视频详情与主页作品列表接口在登出态均不可用，本次**未能完成对抖音数据的独立实时复核**。
这是限制，不是遗漏，必须写进 `FEASIBILITY.md` 与 summary sheet：

> 抖音：作品数据取自平台自身 feed 接口的实时返回（desc/话题/作者/时长/多项互动数一致自洽）；
> 因视频详情与主页作品列表接口在登出态不可用，本次未能完成独立的实时复核，此限制如实记录。

**不要**因为其他平台复核通过就默认抖音也通过 —— 写清楚它没被复核过。

## 踩坑记录

| 问题 | 原因 | 解法 |
|---|---|---|
| 播放量全是 0 | 平台不公开 | 写 N/A，改按点赞排序 |
| `module/feed` 手工构造失败 | 路径校验 | 只用页面自身触发的请求 |
| 主页作品数 = 0 | 登出态风控 | 接受；粉丝数走 profile 接口 |
| Playwright 读 `Response.text()` 报 `UnicodeDecodeError` | gzip 响应 | 改用 `response.body()` 后自行解压，或从 HTML 正则取 |
| 部分账号粉丝数拿不到 | 接口未命中 | 如实记 N/A（实测 21/27 命中） |
