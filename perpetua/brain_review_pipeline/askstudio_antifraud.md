# Ask Studio：YouTube 反作弊视角（2026-10-08）

## YouTube 如何区分真实 vs 虚假播放

**信号维度：**
1. **行为模式**：观看时长、会话深度（是否浏览/点赞/评论/订阅、是否看相关视频）；从不观看的"播放"直接丢弃
2. **互动不匹配**：高播放但 0 点赞/评论 → 标记
3. **速度异常**：与频道历史不一致的突增（50/天 → 50,000/小时）
4. **来源信号**：直接 URL 无 referrer 视为可疑；僵尸网络有可识别的流量签名
5. **IP/设备分析**：同一 IP 重复播放、数据中心 IP、设备指纹异常
6. **技术验证**：embed 来源验证，播放是否真实发起

## 信任上报 vs 独立验证

**YouTube 用服务端独立验证，不信任客户端自报。**
- "YouTube doesn't count views — it validates them"
- 前 301 个播放接受特殊审查；播放先审计再计入公开计数器
- 后续批量复审；变现只按验证过的播放结算

## 分级处理（非立即封禁）

1. **静默过滤**：可疑播放直接不计入（301+ 冻结审计）
2. **延迟批量审计**：定期复审（历史为太平洋时间午夜），事后可见掉量
3. **政策升级**：首次警告 → 内容删除 → 90 天 3 strike 封频道 → 收益追回
4. **推荐降权**：被标记频道推荐曝光降低

**核心原则：先标记过滤，重复/严重才升级处罚。**

## 对 worker 诚实机制的启示

- 不信任 worker 自报"完成"，必须服务端独立验证（对应方案 A：证据链）
- 行为模式基线 + 偏离检测（对应方案 C：行为指纹）
- 速度/数量异常检测（对应方案 D：结果倒查）
- 分级处理：首次标记观察，重复才升级（避免误伤）
