## 十二、Ask Studio 底层算法诊断（2026-10-08 01:44 CST）

### 缺失的爆款变量
1. **0-1.5 秒视觉钩子**：观众不看标题先看画面，第 1 帧没有张力/肢体喜剧/高对比就直接滑走
2. **音频节奏与 TTS 疲劳**：合成音平淡，喜剧节奏差，观众在 punchline 前就流失
3. **循环引擎**：11 秒视频需要重播；硬结尾/黑帧/可预测结局 → 观众 8-9 秒就滑走而不是循环
4. **视觉清晰度 vs 诡异噪点**：slapstick 需要清晰的动作因果；AI 伪影/奇怪物理 → 视觉笑点糊掉

### 被判"拍脑袋"的门禁
| 门禁 | 诊断 |
|------|------|
| 描述 100+ 字符 + CTA | Shorts 观众几乎不点开描述，注意力全在视频画面上 |
| 48h <50 换标题 | 标题对"是否滑走"几乎没影响；换标题救不活一个被秒滑的视频 |
| 强制 emoji/标题格式 | 掉粉是视觉+听觉 payoff 决定的，不是标题有没有 emoji |
| 4 小时间隔 | 执行层面已失效（实际秒级连发），且治标不治本 |

### 根本性误解
1. Shorts 是"躺看"不是"搜索点击"：长视频观众看标题选片，Shorts 观众视频一出现就已经在看了
2. Slapstick 公式疲劳：一天多次发"Karen 找 AI 茬被喷"，老观众一眼认出模板，滑得更快
3. 产量压不住留存：24 条机械化过 checklist，如果测试观众 1 秒内就滑，兴趣直接蒸发

### 最高杠杆变量（按影响排序）
1. **Stayed vs Swiped 比率**（目标 70-80%+；我们约 33%，即 2/3 秒滑）
2. **前 3 秒留存曲线**：0-2 秒陡峭下跌 = 视觉 premise 不清
3. **平均观看百分比**（11 秒视频目标 110-130%+，即看完还循环）
4. **分享率**（每 100 播放的分享数；0 分享 = 笑点没触发情绪）
5. **喜剧微节奏**：2-4 秒升级、8-9 秒 punchline、无缝循环回开场
